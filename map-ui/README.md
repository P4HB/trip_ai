# 제주 여행 추천 베타

프레임워크 없이 실행되는 정적 HTML 추천 UI입니다. 사용자는 동행자, 날짜, 여행 방식, 취향, 조건 확인의 5단계를 차례로 완료한 뒤 장소 추천을 실행합니다. 초기 화면에서는 추천을 자동 실행하지 않으며 이전 단계로 돌아가 선택을 바꾸거나 마지막 확인 화면에서 필수 장소와 결과 설정을 추가할 수 있습니다.

한국관광공사 TourAPI 제주 장소 2,154건 중 정상 좌표 2,153건을 표시하며, 24개 취향 라벨과 Companion 5개·Month 12개가 모두 있는 1,663곳을 `ccu-mmr-v4-session-variants-schedule`로 추천합니다. `balanced` 모드는 관련도 상위 1·2·3위를 각각 첫 seed로 한 코스 3안을 만들고 최초에는 `0.5/0.3/0.2`로 하나를 선택합니다. `다른 코스 보기`는 아직 안 본 코스를 우선하며 이전 Top-N과의 중복·변경 수를 표시합니다. Top-N 카드와 상세에는 기존 v5 웹 조사에서 가져온 활동 설명과 원래 출처를 함께 표시합니다.

여행 시작일·종료일과 자차 여부를 입력하고 장소명·주소·ID 검색 결과에서 필수 장소를 선택하면 근사 일정을 함께 만듭니다. 자차는 중심 반경 15km, 비자차는 5km를 사용하며 하루 capacity는 최대 6곳입니다. 필수 군집과 사용자가 고른 중심을 먼저 보존하고 남은 일자는 현재 코스 Top-N의 반경 밖 장소를 자동 중심으로 채우므로 코스를 바꾸면 일정도 함께 다시 계산됩니다. 오른쪽 일차 카드에 마우스를 올리거나 키보드 포커스를 두면 지도에는 해당 일차 장소만 강조되고, 벗어나면 전체 일정이 복원됩니다.

## 실행

저장소 루트에서 다음 명령을 실행합니다.

```powershell
python -m http.server 8080 -d map-ui
```

그다음 <http://localhost:8080>을 엽니다. 지도 타일과 장소 이미지는 인터넷 연결이 필요합니다.

## 데이터 갱신

현재 데모는 TourAPI와 라벨 snapshot이 모두 `2026-08-09`일 때만 번들을 만듭니다. 원본·라벨을 갱신한 뒤 날짜 상수와 계약을 함께 검토하고 다음 스크립트를 실행합니다.

```powershell
node scripts/build_map_ui_data.mjs
```

지도 라이브러리는 `vendor` 폴더에 포함되어 있으며 실행 시 npm이나 별도의 로그인은 필요하지 않습니다.

## 검증

```powershell
node scripts/test_ccu_mmr.cjs
node scripts/validate_ccu_mmr_dashboard.cjs
```

이 화면은 `ai_draft` 내부 비교용입니다. 웹 조사 문장도 AI 초안이므로 운영시간·가격·휴무·행사 일정은 연결된 원문에서 다시 확인해야 합니다. 일정 군집은 실제 도로·대중교통 이동시간이 아니라 중심과 장소 사이의 Haversine 직선거리만 사용합니다. 날씨·영업·예약·접근성·이동시간·가격을 보장하지 않으며 사용자 입력은 브라우저 메모리에만 남습니다.
