# 제주 여행 추천 베타

프레임워크 없이 실행되는 정적 HTML 추천 UI입니다. 사용자는 동행자, 날짜, 여행 방식, 취향, 조건 확인의 5단계를 차례로 완료한 뒤 장소 추천을 실행합니다. 취향 단계에서는 간단한 프리셋이나 세부 조정 외에 여행 MBTI를 시작할 수 있습니다. A/R·O/I·L/H 축마다 6개씩 총 18개 상황 질문과 최대 3개 적응형 가상 장소 A/B에서 원자 라벨 가중치를 추정하고, 같은 profile을 3축 8개 여행 MBTI로 요약합니다. 결과를 적용해도 추천은 자동 실행하지 않으며 마지막 확인 화면의 명시적 실행 뒤에만 계산합니다.

한국관광공사 TourAPI 제주 장소 2,154건 중 정상 좌표 2,153건을 표시하며, 24개 취향 라벨과 Companion 5개·Month 12개가 모두 있는 1,663곳을 `ccu-mmr-v6-travel-mbti-three-axis`로 추천합니다. 여행 MBTI 유형 문자는 표시·공유 전용이고 실제 추천에는 최대 8개 active feature의 연속 weight만 사용합니다. `balanced` 모드는 관련도 상위 1·2·3위 seed 코스 3안 중 하나를 고르고 `다른 코스 보기`는 아직 안 본 코스를 우선합니다. 추천 목록과 일정의 같은 장소는 1~5 만족도와 최대 300자 의견을 즉시 동기화합니다. 모든 고유 장소의 만족도를 고른 뒤 사용자가 저장 버튼을 누르면 여행 조건·MBTI 상태·추천/일정 결과·피드백을 `travel-recommendation-feedback-log-v2`로 `/travel/api/feedback`에 전송합니다. 서버는 이를 전용 SQLite에 90일 보관하며 실명·연락처·현재 위치·IP는 저장하지 않습니다. Web Storage는 사용하지 않습니다.

여행 시작일·종료일과 자차 여부를 입력하고 장소명·주소·ID 검색 결과에서 필수 장소를 선택하면 근사 일정을 함께 만듭니다. 자차는 중심 반경 15km, 비자차는 5km를 사용하며 하루 capacity는 최대 6곳입니다. 필수 군집과 사용자가 고른 중심을 먼저 보존하고 남은 일자는 현재 코스 Top-N의 반경 밖 장소를 자동 중심으로 채우므로 코스를 바꾸면 일정도 함께 다시 계산됩니다. 오른쪽 일차 카드에 마우스를 올리거나 키보드 포커스를 두면 지도에는 해당 일차 장소만 강조되고, 벗어나면 전체 일정이 복원됩니다.

## 실행

저장소 루트에서 다음 명령을 실행합니다.

```powershell
python -m http.server 8080 -d map-ui
```

그다음 <http://localhost:8080>을 엽니다. 지도 타일과 장소 이미지는 인터넷 연결이 필요합니다.

## 데이터 갱신

현재 데모는 TourAPI와 라벨 snapshot이 모두 `2026-08-09`일 때만 번들을 만듭니다. 원본·라벨을 갱신한 뒤 날짜 상수와 계약을 함께 검토하고 다음 스크립트를 실행합니다.

```powershell
node scripts/build_map_ui_data.mjs
```

지도 라이브러리는 `vendor` 폴더에 포함되어 있으며 실행 시 npm이나 별도의 로그인은 필요하지 않습니다.

## 검증

```powershell
node scripts/test_preference_elicitation.cjs
node scripts/test_ccu_mmr.cjs
node scripts/validate_ccu_mmr_dashboard.cjs
```

이 화면은 `ai_draft` 내부 비교용입니다. 웹 조사 문장도 AI 초안이므로 운영시간·가격·휴무·행사 일정은 연결된 원문에서 다시 확인해야 합니다. 일정 군집은 실제 도로·대중교통 이동시간이 아니라 중심과 장소 사이의 Haversine 직선거리만 사용합니다. 날씨·영업·예약·접근성·이동시간·가격을 보장하지 않습니다. 사용자 입력과 여행 MBTI 프로필은 기본적으로 브라우저 메모리에만 남고, 모든 만족도 완료 뒤 사용자가 평가 로그 저장을 누른 경우에만 서버에 90일간 저장됩니다. 공유 문구에는 유형 코드·이름·공개 설명만 포함합니다.
