# 제주 플레이스 맵

프레임워크나 빌드 과정 없이 실행되는 정적 HTML 지도입니다. 한국관광공사 TourAPI에서 수집한 제주 장소 2,154건 중 정상 좌표 2,153건을 표시합니다. 라벨 데이터가 있는 1,663개 지도 장소는 상세 패널에서 Theme·Environment·Style 24축 값을 확인할 수 있습니다.

각 라벨에 마우스를 올리거나 키보드로 focus하면 라벨 설명과 현재 점수의 의미가 표시됩니다. 일반 음식·주점처럼 현재 라벨 범위 밖인 장소는 상세 패널에 라벨 미제공 상태를 표시합니다.

## 실행

가장 간단한 방법은 `index.html`을 더블클릭하는 것입니다. 브라우저의 로컬 파일 정책 때문에 문제가 생기면 저장소 루트에서 다음 명령을 실행합니다.

```powershell
python -m http.server 8080 -d map-ui
```

그다음 <http://localhost:8080>을 엽니다. 지도 타일과 장소 이미지는 인터넷 연결이 필요합니다.

## 데이터 갱신

새 TourAPI 데이터셋을 수집한 뒤 저장소 루트에서 다음 스크립트를 실행하면 가장 최근 날짜 폴더를 찾아 지도 장소와 같은 날짜의 라벨 번들을 다시 만듭니다.

```powershell
node scripts/build_map_ui_data.mjs
```

생성 파일은 `data/jeju-places.js`와 `data/jeju-place-labels.js`입니다. 같은 날짜의 `place-preference-label-v2`가 없으면 지도는 그대로 동작하고 라벨 번들은 미제공 상태로 생성됩니다.

지도 라이브러리는 `vendor` 폴더에 포함되어 있으며 실행 시 npm이나 별도의 로그인은 필요하지 않습니다.
