- 관련 이슈: 사용자 요청 — 장소 상세의 작고 과도하게 잘리는 대표 사진 개선

## 배경

현재 장소 상세 카드는 데스크톱에서 대표 이미지를 폭 180~230px의 왼쪽 grid 열에 넣고 상세 내용 높이만큼 늘린다. 이미지는 `object-fit: cover`이므로 일반적인 가로 사진이 좁고 긴 영역에 맞춰지면서 좌우 대부분이 잘린다. 760px 이하의 후속 반응형 규칙도 이미지 높이를 135px로 고정해 세로·정사각형 이미지가 과도하게 잘린다. 원본이 작은 경우에는 컨테이너 전체로 확대되어 흐릿해질 수 있다.

## 목표

- 장소 상세의 기본 상태에서 대표 이미지 전체를 왜곡이나 과도한 잘림 없이 보여준다.
- 데스크톱과 모바일 모두 사진 영역을 현재보다 크게 제공한다.
- 남는 여백은 동일 이미지의 흐린 배경으로 채워 완성도를 유지한다.
- 저해상도 이미지는 과도하게 확대하지 않는다.
- 대표 사진을 누르면 원본 비율의 큰 이미지 뷰어를 제공한다.

## 비목표

- TourAPI 이미지 원본 교체·재수집·보정
- 여러 사진 갤러리 또는 Kakao 사진 수집
- 이미지 CDN·서버 프록시·캐시 도입
- 장소 상세의 추천·리뷰·라벨 데이터 계약 변경

## 요구사항

- `REQ-6801`: 데스크톱 상세 카드의 이미지 열을 280~320px 수준으로 확대하고 상세 텍스트 높이와 무관한 4:3 미디어 영역으로 표시한다.
- `REQ-6802`: 대표 이미지는 `object-fit: contain`으로 전체를 표시하고 동일 이미지의 흐린 backdrop이 남는 영역을 채운다.
- `REQ-6803`: 760px 이하에서는 상세 내용 위의 전체 폭 16:9 미디어 영역을 최소 200px 높이로 제공한다.
- `REQ-6804`: 이미지의 자연 크기가 표시 영역보다 현저히 작으면 원본을 과도하게 확대하지 않는다.
- `REQ-6805`: 이미지 클릭 또는 키보드 활성화로 modal 이미지 뷰어를 열고 닫기 버튼·Escape·backdrop으로 닫을 수 있다.
- `REQ-6806`: 뷰어를 닫으면 상세 사진 버튼으로 포커스를 복원하며 dialog의 제목과 이미지 대체 텍스트를 장소명으로 제공한다.
- `REQ-6807`: 이미지 누락·로드 실패 시 기존 placeholder를 표시하고 확대 동작을 비활성화한다.
- `REQ-6808`: 장소 전환 중 이전 이미지의 지연 load/error가 새 상세 상태를 덮어쓰지 않는다.
- `REQ-6809`: 추천, 상세 설명, 리뷰, 점수 trace, 라벨, 지도 동작은 유지한다.

## 입력과 출력

입력은 기존 `place.image` HTTPS URL과 `place.title`이다. 새 서버 요청이나 저장 데이터는 없다. 런타임 출력은 이미지 load 상태, `naturalWidth`·`naturalHeight` 기반 저해상도 클래스, native dialog의 열림 상태뿐이며 Web Storage를 사용하지 않는다.

## 설계

```text
장소 선택
  → 기존 place.image 로드
  → 성공: 흐린 backdrop + contain 대표 이미지 + 크게 보기 버튼
  → 작은 원본: contain 이미지의 자동 확대 제한
  → 실패/누락: 기존 placeholder

대표 이미지 활성화
  → native modal dialog
  → 원본 비율 contain 표시
  → 닫기/Escape/backdrop → 상세 이미지 버튼 포커스 복원
```

## 예외와 폴백

- 이미지 URL이 없거나 load에 실패하면 backdrop과 버튼을 숨기고 placeholder만 표시한다.
- 장소를 빠르게 바꿀 때 handler는 현재 선택 장소 ID와 요청 URL을 확인하고 오래된 이벤트를 무시한다.
- native dialog를 지원하지 않는 환경에서는 `showModal` 대신 `open` 속성으로 표시하고 동일 닫기 버튼을 제공한다.
- 외부 이미지 서버의 CORS는 픽셀 데이터에 접근하지 않으므로 추가 권한이 필요 없다.

## 승인 기준

- `AC-6801`: 가로·세로·정사각형 대표 이미지가 데스크톱과 모바일 기본 상세에서 전체 비율로 보인다.
- `AC-6802`: 데스크톱 이미지 영역은 4:3·최대 320px 열이며 상세 내용이 길어져도 세로로 늘어나지 않는다.
- `AC-6803`: 760px 이하에서 이미지는 내용 위 전체 폭·16:9·최소 200px로 표시된다.
- `AC-6804`: 작은 원본은 과도하게 확대되지 않고 누락·실패 이미지는 placeholder로 폴백한다.
- `AC-6805`: 클릭·키보드로 큰 이미지 dialog를 열고 닫기·Escape·backdrop으로 닫은 뒤 포커스가 복원된다.

## 구현 결과

- 데스크톱 상세 카드 이미지 열을 화면 폭에 따라 280~320px로 확대하고, 상세 내용 높이와 독립된 4:3 frame으로 고정했다.
- 760px 이하에서는 상세 내용 위 전체 폭 16:9 frame과 최소 높이 200px를 적용했다.
- 대표 이미지는 `contain`으로 전체를 표시하고 같은 이미지의 blur backdrop으로 남는 영역을 채운다.
- 독립 `Image` preloader와 증가 token으로 성공한 현재 장소 이미지만 DOM에 반영하며, 실제 표시 배율이 1.35배를 넘는 작은 원본은 자동 확대를 제한한다.
- 사진 버튼에서 native modal dialog를 열고 닫기·Escape·backdrop 닫기, 장소명 대체 텍스트와 포커스 복원을 구현했다.
- 이미지가 없는 실제 장소 `제주절물자연휴양림`에서 버튼·backdrop 비표시와 placeholder 폴백을 확인했다.

## 설계와 달라진 점

- 저해상도 판정은 고정 픽셀 임계값 대신 현재 미디어 frame과 원본 자연 크기의 실제 확대 배율을 계산해 1.35배 초과일 때 적용했다. 세로·가로 원본을 같은 기준으로 처리하기 위함이다.

## 알려진 제한

- 원본 자체가 저해상도이거나 잘못 촬영된 경우 선명도를 새로 생성하지 않는다.
- 기존 데이터는 장소당 대표 이미지 한 장만 제공한다.
