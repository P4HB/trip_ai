## 배경

해결하려는 문제와 현재 동작을 사실 중심으로 작성한다.

## 목표

- 이번 변경으로 달성할 결과를 작성한다.

## 비목표

- 이번 변경에서 의도적으로 다루지 않는 범위를 작성한다.

## 요구사항

- `REQ-001`:
- `REQ-002`:

## 입력과 출력

입력값, 출력값, 데이터 타입, 필수 여부, 단위, 좌표 순서, 시간대를 명시한다.

## 설계

컴포넌트 흐름, 데이터 흐름, 알고리즘 또는 UI 상태 전이를 작성한다. 구현되지 않은 내용은 명확히 표시한다.

## 예외와 폴백

누락 데이터, 외부 서비스 실패, 빈 결과, 시간 초과, 잘못된 입력에 대한 동작을 작성한다.
