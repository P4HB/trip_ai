# SPEC-093: 글로벌 목표 시장·국내 경쟁사·초기 고객 선정 기준 정정

- 상태: Implemented
- 작성일: 2026-09-30
- 최종 수정일: 2026-09-30
- 관련 이슈: 사용자 지정 TAM, 국내 트립빌더 비교와 당사 관점의 고객 선정 기준 반영
- 관련 문서: [문서 색인](README.md), [직전 정정](spec_092.md), [사업 기준 문서](business_model_and_social_impact.md)
- 관련 코드: 제품 실행 코드 변경 없음
- 선행 SPEC: SPEC-091, SPEC-092

## 배경

기존 제출 Spec은 TAM을 국내 기업·기관의 추천 솔루션 수요로 좁게 정의했다. 초기 고객 선정도 고객이 수행할 수 있는 일에 치우쳐 있었다. 사용자는 TAM을 전 세계 여행시장으로 지정하고, 국내 트립빌더를 경쟁 서비스에 추가하며, 우리에게 어떤 고객인지와 접촉 용이성 등을 기준으로 초기 고객을 선정하도록 요청했다.

## 목표

- 전 세계 여행시장 안에서 상품과 초기 진입의 범위를 구분한다.
- 국내 직접 경쟁 서비스인 트립빌더의 공개 기능·공급 방식을 비교한다.
- 거래 접근성과 사업적 가치를 기준으로 초기 고객과 영업 우선순위를 정한다.

## 비목표

- 임의 시장 규모·점유율·계약 수·가격·경쟁 우위 작성.
- 실제 고객 접촉, 계약, 해외 서비스 출시 또는 제품 기능 변경.

## 요구사항

- REQ-001: TAM은 전 세계 여행시장, SAM은 개인화 여행 추천·일정 계획 및 관광 데이터 솔루션 시장, SOM은 국내에서 접촉·도입을 추진할 수 있는 초기 기업·기관 고객군으로 정리한다. 제주 MVP는 초기 공급 자산으로 설명한다.
- REQ-002: 트립빌더 공식 소개를 확인해 국내 경쟁 서비스로 추가한다. 추천·일정 기능과 B2B·B2G 공급을 비교하고 출처를 표시한다.
- REQ-003: 고객 선별 기준을 사업적 적합성, 접촉 용이성, 의사결정자 접근성, 계약 속도, 초기 공급 비용과 후속 사업 가치로 작성한다. 특정 업체와의 관계·구매 의사·예산을 확보한 사실로 표현하지 않는다.
- REQ-004: 시장 규모 전체에 일괄 적용했던 고객 수×계약액 산식을 초기 매출 계획으로 한정한다. 관련 영업 흐름·전략 보완·평가 대조·사업 기준 문서를 동기화하고 기존 앱 요구사항·도면 연결은 유지한다.

## 입력과 출력

- 입력: 사용자 수정 지시, 제출 Spec v1.4, 트립빌더 공식 소개.
- 출력: 시장·경쟁·고객 선정 및 연결 설명을 수정한 Markdown.

## 설계

제출 Spec §3.1에서 세계 여행산업의 범위, 개인화 추천 상품이 대응하는 수요, 초기 확보할 고객을 순차적으로 좁힌다. §3.2에는 트립빌더를 직접 경쟁 대상으로 추가하고 §8에 출처를 연결한다. §4.2는 당사 관점의 선정 기준 표로 교체하고 §5.3의 최초 고객 탐색 순서에도 반영한다. 초기 고객의 기능 수행 능력을 영업 우선순위로 다시 쓰지 않는다. 사업 기준 문서에는 변경된 시장 방향과 제출 Spec 링크만 기록해 상세 정의를 중복하지 않는다.

## 예외와 폴백

시장 수치·해외 진출 국가·일정은 새로 정하지 않는다. 경쟁사의 공식 설명을 실제 성능 시험이나 Trip AI의 성과로 해석하지 않는다.

## 구현 결과

- 사업 개요와 §3.1의 TAM을 전 세계 여행시장으로 수정했다. SAM은 개인화 여행 추천·일정 계획·관광 데이터 솔루션, SOM은 국내에서 접근·거래를 추진할 초기 고객으로 구분했다. 고객 수×연간 계약액은 초기 매출 계획에 적용했다.
- §3.2와 §8에 국내 트립빌더를 추가했다. 2026-09-30 공식 소개에서 취향·동행 조건 추천, AI 여행비서·일정 편집, 파트너 SaaS·Chat API와 공공 스마트관광 공급을 확인했다. 동일 여행 과제에서 비교할 기준을 기획했으며 성능 우위를 주장하지 않았다.
- §4.2를 당사 관점의 선정 기준 6개로 교체하고 §5.3의 최초 영업 순서와 전략 보완 문서를 동기화했다. 구매자가 무엇을 할 수 있는지가 아니라 우리가 접촉·제안·계약하기에 어떤 고객인지와 후속 사업 가치를 설명했다.
- 사업 기준 문서의 시장 방향과 평가 대조 기록을 동기화했다. 편집 전 제출 원고는 `kaist_app/_work/spec_v1.4_before_global_market_revision.md`에 보존했다.
- AC-001: 전 세계 TAM, 상품 범위의 SAM, 초기 고객 SOM 및 초기 매출 산식 대조 통과.
- AC-002: 공식 소개와 경쟁 비교 문장·출처 연결 대조 통과.
- AC-003: 고객 선정의 6개 기준과 최초 영업·보완 설명의 의미 대조 통과.
- AC-004: 기존 REQ·AC·NFR·BP·상품·화면·예외·시험 ID 집합과 8장 구성 보존. 수정 문서 표 29개 열 수, 로컬 링크 8개, 인코딩 검사 통과. `git diff --check -- docs/README.md docs/business_model_and_social_impact.md` 통과.
