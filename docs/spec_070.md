# SPEC-070: 9월 3일 이후 익명 테스터 피드백 HTML 리포트

- 상태: Implemented
- 작성일: 2026-09-09
- 최종 수정일: 2026-09-09
- 관련 이슈: 사용자 요청 — JSON 테스터 로그를 피드백 검토용 HTML로 정리
- 관련 문서: [SPEC-060](spec_060.md), [SPEC-069](spec_069.md), [안전 및 개인정보](safety_privacy.md)
- 관련 코드: `scripts/build_feedback_report.mjs`, `reports/travel-feedback-since-0903.html`
- 선행 SPEC: SPEC-060, SPEC-069

## 배경

9월 3일 이후 추천 평가 로그가 `anonymized-feedback-v1` JSON으로 정리됐지만, 원본은 중첩 구조가 깊고 40만 자 이상이라 전체 경향과 사용자별 의견을 빠르게 비교하기 어렵다.

## 목표

- 원본 JSON을 읽어 브라우저에서 바로 열 수 있는 단일 HTML 리포트를 생성한다.
- 전체 완료율·평균 점수·점수 분포와 자유 의견을 우선 노출한다.
- 사용자, 점수, 의견 유무, 장소명 검색으로 평가를 좁혀 볼 수 있게 한다.
- 사용자별 입력 조건과 세션별 평가를 상세 확인할 수 있게 한다.

## 비목표

- AI가 자유 의견의 의미나 감정을 확정적으로 분류하는 기능
- 원본 로그 수정, 서버 조회, 운영 대시보드 배포
- 익명화 전 이름, 시각, 정확한 여행 날짜 복원

## 요구사항

- `REQ-7001`: `travel-feedback-anonymized-since-0903 copy.json`의 `summary`, `logs`, `reviews`를 읽어 단일 HTML을 생성한다.
- `REQ-7002`: 전체 로그·사용자·평가 완료율·평균 점수·자유 의견 수와 1~5점 분포를 표시한다.
- `REQ-7003`: 낮은 점수 의견과 전체 자유 의견을 사용자가 바로 읽을 수 있게 우선순위 높은 영역에 표시한다.
- `REQ-7004`: 사용자·점수·의견 유무 필터와 장소·의견 검색을 제공하고 결과 수를 동기화한다.
- `REQ-7005`: 세션별 여행 MBTI, 동행, 여행 일수, 평가 완료 현황, 장소 평가를 표시한다.
- `REQ-7006`: 외부 라이브러리·네트워크 요청 없이 로컬 파일로 동작하며 원본에 없는 개인정보를 생성하지 않는다.
- `REQ-7007`: 입력 스키마와 필수 배열을 검증하고 잘못된 입력에서는 생성에 실패한다.
- `REQ-7008`: 익명 사용자별 여행 MBTI 세 축을 일상어로 풀고, 고평가 패턴과 저평가 이유를 실제 점수·자유 의견·이동 조건에 근거해 요약한다.
- `REQ-7009`: 사용자별 해석은 관찰된 사실과 해석을 구분하고, 자유 의견이나 평가 완료율이 낮으면 근거 부족을 명시한다.

## 입력과 출력

- 입력: 저장소 루트의 `travel-feedback-anonymized-since-0903 copy.json`, 스키마 `anonymized-feedback-v1`
- 출력: `reports/travel-feedback-since-0903.html`, UTF-8 단일 파일
- 시간 범위: 원본 주석에 정의된 9월 3일 이후 세션. 기록 시각과 여행 날짜는 원본에서 제외됨.

## 설계

생성 스크립트가 JSON을 검증한 뒤 안전하게 직렬화해 HTML에 내장한다. HTML은 요약 카드, 점수 분포, 사용자별 취향·평가 해석, 주목할 의견, 탐색 가능한 전체 평가, 사용자별 세션 상세로 구성한다.

사용자별 해석은 여행 MBTI의 `A/R`(활동/휴식), `O/I`(야외/실내), `L/H`(로컬/핫스폿)를 풀어 쓰고, 4~5점 장소와 1~2점 장소 및 자유 의견을 함께 대조한다. 낮은 점수 이유는 의견에 직접 드러난 경우만 구체화하고, 의견이 없으면 점수만으로 이유를 단정하지 않는다. 제품 사용성에 관한 의견은 여행지 선호와 별도로 표시한다.

## 예외와 폴백

- `schema`가 다르거나 `logs` 또는 각 로그의 `reviews`가 배열이 아니면 명확한 오류로 중단한다.
- 평가가 없으면 평균과 분포는 0 또는 `—`로 표시한다.
- 누락된 선택 조건은 `미지정`으로 표시하고 추측하지 않는다.

## 구현 결과

`scripts/build_feedback_report.mjs`가 `anonymized-feedback-v1` 입력을 검증하고 원본 요약과 재계산 집계를 대조한 뒤 외부 의존성 없는 단일 HTML을 생성한다.

`reports/travel-feedback-since-0903.html`에 전체 현황 카드, 1~5점 분포, 수집 상태, 1~2점 자유 의견 우선 목록, 전체 183건 검색·필터·CSV 저장, 사용자별 10개 세션 상세를 구현했다. 원본에 없는 의미 분류나 감정 추론은 추가하지 않았으며 장소 평가 문장은 그대로 표시한다.

후속 요청으로 9명 각각의 분석 카드를 추가했다. 카드에는 MBTI 코드·유형명·세 축의 의미와 경향 강도, 여행 취향 풀어쓰기, 추천 평가 패턴, 4~5점 장소 근거, 낮거나 상대적으로 낮은 점수의 이유, 해석 한계를 표시한다. 사용자 B·C·H처럼 일정 반복·체력·이동 조건이 낮은 점수와 연결되는 경우는 원문 근거를 요약했고, 사용자 E의 제품 사용성 의견은 장소 선호와 분리했다. 사용자 D·G처럼 자유 의견이나 평가 수가 부족한 경우는 원인을 단정하지 않았다.

검증 결과:

- `node --check scripts/build_feedback_report.mjs`: 통과
- `node scripts/build_feedback_report.mjs --check`: 통과, 사용자 9명·세션 10개·평가 133개·의견 60개
- `git diff --check`: 통과
- 데스크톱 브라우저: 요약·차트·183개 평가·10개 세션 렌더링, 장소 검색 8건 필터 동기화 확인
- 모바일 390×844: 요약 카드와 의견 카드 단일 열 반응형 표시 확인
- 사용자 분석 후 재검증: 9개 분석 카드 렌더링, 축별 경향 강도·추천 평가·낮은 점수 이유·해석 한계 표시, 데스크톱 2열과 모바일 1열 가독성 확인
