## 배경

AGENTS.md와 README.md는 제품을 "여행지와 일정을 추천하는 AI", "제주 플레이스 지도 MVP"로 서술했다. 실제 제품 방향은 인스타그램 게시물·릴스에서 장소를 모아 지역별 여행 일정을 만드는 것이며, 제주 구현은 그 방향을 검증하는 첫 지역이다. 작업 지침 파일이 제주를 제품 범위로 읽히게 하면 에이전트가 제주 전용 가정을 공통 구조에 넣을 위험이 있다.

### 사실·결정

| 구분 | 내용 |
|---|---|
| 사용자 확정 | 서비스 본질은 인스타 게시물·릴스 → 장소 확인 → 지역별 저장 → 지역별 일정이다. |
| 사용자 확정 | 제주는 PoC(MVP) 범위이며 서비스 본질이 아니다. AGENTS.md와 README.md에 명시한다. |
| 미결정 | 제주 다음 확대 지역과 순서, 지역 확대 시 라벨 체계 |

## 목표
