# SPEC-086: 프로젝트 코드 지식 그래프 연동 제거

- 상태: Implemented
- 작성일: 2026-09-15
- 최종 수정일: 2026-09-15
- 관련 이슈: 자동 그래프 갱신으로 인한 개발·에이전트 작업 성능 저하
- 관련 문서: [문서 색인](README.md), 루트 `AGENTS.md`
- 관련 코드: 프로젝트 전용 에이전트 스킬, 생성 그래프 디렉터리, Git hook·merge driver 설정
- 선행 SPEC: SPEC-061

## 배경

프로젝트에는 코드 지식 그래프 산출물과 전용 에이전트 스킬이 있으며, commit과 checkout 뒤 자동 갱신하는 Git hook도 설치되어 있다. 현재 그래프는 4,399개 노드를 포함하고 있고 hook은 별도 Python 프로세스로 전체 변경을 분석하므로 로컬 개발과 에이전트 세션의 준비·종료 시간을 늘릴 수 있다. 사용자는 성능 저하 우려로 이 저장소의 해당 연동을 모두 제거하도록 요청했다.

## 목표

- 프로젝트 전용 코드 지식 그래프 스킬·산출물·설정·지침을 제거한다.
- commit과 checkout 뒤 실행되는 자동 그래프 갱신을 중단한다.
- 기존 제품 코드와 사용자의 다른 미커밋 변경을 보존한다.

## 비목표

- 사용자 환경에 전역 설치된 Python 패키지 제거
- 추천 만족도 저장 DB 이전 구현
- 지도·추천·평가 API의 런타임 동작 변경

## 요구사항

- `REQ-8401`: 프로젝트 전용 스킬과 생성 그래프 산출물을 제거해야 한다.
- `REQ-8402`: 루트 에이전트 지침과 문서에서 해당 도구를 필수로 사용하는 규칙을 제거해야 한다.
- `REQ-8403`: post-commit·post-checkout 자동 실행과 로컬 merge driver 설정을 제거해야 한다.
- `REQ-8404`: 다른 도구·제품 코드·사용자 미커밋 변경을 변경하거나 삭제하지 않아야 한다.
- `REQ-8405`: 과거 SPEC의 현재 작업 절차에 남은 그래프 갱신 요구를 제거해야 한다.

## 입력과 출력

- 입력: 현재 저장소의 프로젝트 전용 코드 지식 그래프 연동 파일과 로컬 Git 설정
- 출력: 자동 그래프 작업이 없는 저장소와 Git 작업 흐름
- 데이터 스키마·외부 인터페이스 변경: 없음

## 설계

프로젝트에 추가된 전용 스킬 디렉터리와 생성 산출물 디렉터리를 삭제한다. 루트 에이전트 지침의 지식 그래프 섹션, 그래프 JSON용 attributes, 전용 SPEC과 다른 SPEC의 그래프 검증 항목을 정리한다. 로컬 Git hook은 설치 전 기존 hook이 없었다는 SPEC-061 기록과 현재 파일이 도구 전용 블록으로만 구성된 사실을 확인한 뒤 삭제하고, 로컬 merge driver 섹션도 제거한다.

## 예외와 폴백

- hook 파일에 도구 외 사용자 내용이 있으면 파일 전체를 삭제하지 않고 전용 블록만 제거한다.
- 전역 설치 패키지는 다른 저장소에서 사용할 수 있으므로 유지한다.
- 사용자의 다른 미커밋 변경과 겹치면 해당 부분을 보존하고 도구 관련 줄만 수정한다.

## 승인 기준

- `AC-8401`: 프로젝트 작업 트리와 로컬 Git 설정에 제거 대상 도구 이름·경로·hook이 남지 않는다.
- `AC-8402`: commit과 checkout이 자동 그래프 재생성 프로세스를 시작하지 않는다.
- `AC-8403`: 제품 코드에는 변경이 없고 기존 사용자 변경은 보존된다.
- `AC-8404`: 문서 색인과 본 SPEC이 실제 제거 결과와 일치한다.

## 구현 결과

- 프로젝트 전용 에이전트 스킬 디렉터리와 4,399노드 생성 그래프·캐시·보고서 디렉터리를 제거했다.
- 루트 에이전트 지침의 전용 탐색·갱신 규칙, 그래프 JSON merge attributes, SPEC-061과 다른 SPEC의 그래프 갱신 요구를 제거했다.
- 도구 전용 post-commit·post-checkout hook과 로컬 Git merge driver 설정을 제거했다. 두 hook에는 사용자 정의 블록이 없었다.
- 저장소 전체 문자열·경로 검사 결과 제거 대상 이름과 경로가 남지 않았고, 두 hook과 로컬 Git 설정도 부재함을 확인했다.
- `git pull --ff-only` 결과 GitHub `main`은 이미 최신 상태였다.
- 지도·추천·평가 API 제품 코드는 변경하지 않았고, 작업 시작 전 존재하던 다른 수정·미추적 파일은 보존했다.
- `git diff --check`를 통과했다.
