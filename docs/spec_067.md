- 상태: Implemented
- 작성일: 2026-09-02

- 관련 이슈: 사용자 요청 — 왼쪽 여행 선택 패널을 접고 지도 왼쪽에서 다시 펼치기
- 관련 문서: `docs/architecture.md`, `docs/spec_020.md`, `docs/spec_062.md`
- 관련 코드: `map-ui/index.html`, `map-ui/styles.css`, `map-ui/app.js`, `scripts/validate_ccu_mmr_dashboard.cjs`
- 선행 SPEC: SPEC-020, SPEC-062

## 배경

현재 1,240px 초과 데스크톱 화면은 `여행 선택 패널 → 지도 → 추천 결과` 3열을 고정 표시한다. 사용자가 지도 영역을 넓게 보고 싶어도 왼쪽 선택 패널을 숨길 수 없다. 1,240px 이하에는 이미 상단 버튼과 드로어 방식이 있고, 760px 이하에는 입력·결과·지도의 단일 세로 흐름이 구현되어 있다.

## 목표

- 데스크톱 왼쪽 선택 패널 우측 상단에 명시적인 `접기` 버튼을 제공한다.
- 접힌 상태에서는 지도가 왼쪽으로 확장되고 지도 왼쪽에 `선택지 펼치기` 버튼을 제공한다.
- 접기·펼치기 중 현재 입력, 추천 결과, 지도 선택 상태를 유지한다.
- 레이아웃 전환 후 Leaflet 지도의 크기와 마커 표시를 다시 계산한다.

## 비목표

- 오른쪽 추천 결과 패널 접기
- 접힘 상태의 브라우저 영구 저장
- 1,240px 이하 태블릿 드로어 또는 760px 이하 모바일 단일 스크롤 변경
- 추천 알고리즘·입력·결과·피드백 계약 변경

## 요구사항

- `REQ-6701`: 1,240px 초과에서 선택 패널 우측 상단에 `접기` 버튼을 표시한다.
- `REQ-6702`: 접기 버튼은 `aria-controls=sidebar`, 접힘 상태를 나타내는 `aria-expanded`와 설명 가능한 레이블을 가진다.
- `REQ-6703`: 접으면 선택 패널 열 너비가 0이 되고 지도 열이 확장되며 오른쪽 결과 패널은 유지된다.
- `REQ-6704`: 접힌 상태에서 지도 왼쪽에 `선택지 펼치기` 버튼을 표시하고 키보드 포커스를 이동한다.
- `REQ-6705`: 펼치면 기존 3열 너비를 복원하고 접기 버튼으로 포커스를 되돌린다.
- `REQ-6706`: 접기·펼치기는 폼 값, wizard 단계, 추천·일정, 장소 상세과 피드백 상태를 초기화하지 않는다.
- `REQ-6707`: 레이아웃 전환 직후와 전환 종료 시 지도 `invalidateSize`를 호출한다.
- `REQ-6708`: 1,240px 이하에서는 신규 두 버튼을 숨기고 기존 드로어·모바일 흐름을 유지한다. 접힌 채 breakpoint 아래로 내려가면 데스크톱 접힘 상태를 해제한다.
- `REQ-6709`: 동작은 현재 탭 메모리에만 있고 Web Storage를 사용하지 않는다.

## 입력과 출력

추가 데이터 입력·API 출력은 없다. UI 상태는 `state.sidebarCollapsed: boolean`이며 DOM의 `body.sidebar-collapsed` 클래스와 두 버튼의 `hidden`, `aria-expanded`를 동기화한다.

## 설계

```text
데스크톱 3열
  접기 클릭 → sidebarCollapsed=true → 왼쪽 grid column 0 → 지도 확장
  펼치기 클릭 → sidebarCollapsed=false → 기존 sidebar width 복원

태블릿·모바일
  기존 drawer/stacked flow 유지, 신규 상태 비활성
```

접힌 sidebar는 DOM과 폼 상태를 제거하지 않고 `visibility`, `opacity`, `pointer-events`만 비활성화한다. 펼치기 버튼은 `map-shell` 안에 두어 확장된 지도의 왼쪽 가장자리에서 접근 가능하게 한다.

## 예외와 폴백

- 지도 초기화 전 접기·펼치기를 눌러도 오류 없이 DOM 상태만 바꾸고 optional map 호출을 건너뛴다.
- resize로 1,240px 이하가 되면 접힘을 해제하고 기존 responsive 규칙에 위임한다.
- `prefers-reduced-motion`에서는 기존 전환 축소 정책을 따른다.

## 승인 기준

- `AC-6701`: 데스크톱에서 `접기` 클릭 시 왼쪽 패널이 사라지고 지도가 해당 공간까지 확장된다.
- `AC-6702`: 접힌 상태의 지도 왼쪽에 `선택지 펼치기` 버튼이 보이고 클릭 시 원래 3열이 복원된다.
- `AC-6703`: 접기 전 선택한 동행자·현재 wizard 단계와 지도·추천 상태가 펼친 뒤 유지된다.
- `AC-6704`: 두 버튼의 접근성 속성과 포커스 이동이 상태와 일치한다.
- `AC-6705`: 1,240px 이하에서 신규 버튼이 표시되지 않고 기존 태블릿·모바일 동작이 유지된다.
- `AC-6706`: JavaScript 문법, 정적 dashboard 계약, CCU-MMR 회귀와 데스크톱 브라우저 QA가 통과한다.

## 구현 결과

- `map-ui/index.html`에 데스크톱 전용 `접기`와 지도 위 `선택지 펼치기` 버튼을 추가하고 `aria-controls`, `aria-expanded`, 상태별 레이블을 연결했다.
- `map-ui/app.js`가 `sidebarCollapsed` 메모리 상태와 DOM을 동기화하고, 접기·펼치기 후 키보드 포커스와 Leaflet 크기를 갱신한다.
- `map-ui/styles.css`는 1,240px 초과에서만 왼쪽 grid column을 `0`으로 전환하고 지도 열을 확장한다. 1,240px 이하에서는 신규 버튼을 숨긴다.
- 실제 1,920×900 브라우저에서 sidebar `440px → 0px`, map `1,060px → 1,500px` 전환과 펼친 뒤 원래 너비 복원, 선택값 유지, 양방향 포커스 이동을 확인했다.
- 1,240×900과 760×844에서 신규 버튼 비표시와 데스크톱 접힘 상태 비활성을 확인했다.

## 설계와 달라진 점

- 기능 범위 차이는 없다. 클릭한 펼치기 버튼이 숨겨진 뒤 브라우저 기본 포커스 처리와 충돌하지 않도록, 전환 시간 뒤 복원된 접기 버튼에 포커스를 둔다.

## 알려진 제한

- 접힘 상태는 새로고침 후 복원하지 않는다.
