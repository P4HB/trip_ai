# SPEC-077: 남은 장소 유형 8곳 사용자 확정

- 상태: Implemented
- 작성일: 2026-09-11
- 관련 문서: [SPEC-076](spec_076.md), [데이터 계약](data_contracts.md)
- 관련 코드: `config/place_type_taxonomy.v1.json`, `scripts/test_place_types.py`

## 배경과 목표
사용자가 남은 검토 8곳을 최초 제안 그대로 승인했다. 이 8곳만 사용자 확정으로 변경한다.

## 비목표
유형 변경, 새로운 분류, 나머지 장소의 사람 검수 표시, 하루 상한 적용.

## 요구사항
- REQ-001: 비체올린은 theme_park, 노리매공원·스누피가든·보롬왓은 garden, 서귀포 패류화석산지는 cave_geology, 디앤디파트먼트는 shopping, 하우스오브레퓨즈·코코컬처클럽은 culture_learning을 유지한다.
- REQ-002: 해당 8곳에 사용자 승인 근거와 날짜를 기록하고 user_confirmed로 변경한다. 나머지 유형·확정 상태는 유지한다.
- REQ-003: JSONL·SQLite·검토 큐·보고서·manifest를 재생성한다. taxonomy version은 v1.2-review-complete로 올린다.

## 입력과 출력·설계
SPEC-075/076의 기존 경로와 사용자 확정 메타데이터 구조를 재사용한다. 구현: 남은 검토 ID만 승인 기록 → 재생성 → 검증.

## 예외와 폴백
검토 ID와 예상 유형이 불일치하면 중단한다. 원본 지도·엔진·DB는 수정하지 않는다.

## 영향 범위
분류 설정·테스트·파생 산출물·문서. 원본 마이그레이션 없음.

## 승인 기준과 테스트 계획
- AC-001: 2,153개 ID, 사용자 확정 27곳, 자동 분류 2,126곳, 검토 0곳.
- AC-002: 지정 8곳은 최초 유형을 유지하고 다른 장소도 기존 유형·상태를 유지한다.
- AC-003: `python scripts/test_place_types.py`의 SQLite 일치·재현성·원본 보존 검증 통과.

## 구현 결과
8곳의 최초 유형을 유지하며 사용자 확정을 추가했다. 현재 총 2,153곳, 사용자 확정 27곳, 규칙 판정 2,126곳, 검토 필요 0곳이다. 전체 유형별 건수는 SPEC-076 이후와 동일하다.

## 검증 결과
`python scripts/test_place_types.py` 통과. 27곳 명시적 확정 유형과 출처, 나머지 2,126곳 최초 유형·상태 보존, 검토 큐 0곳, SQLite·JSONL 일치와 재현성·원본 불변을 확인했다.

## 설계와 달라진 점
없음.
